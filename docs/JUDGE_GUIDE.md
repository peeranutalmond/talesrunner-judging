# Judge Guide

1. Choose your name and enter your PIN.
2. Review one artwork at a time.
3. Other judges' scores, averages, totals, and ranking are intentionally hidden.
4. Enter every criterion score. Autosave starts only when all required values (and a required comment, if configured) are valid. Saved appears only after the server confirms the transaction.
5. Use `Enter` for Save & Next, arrow keys to move, `Space` for fullscreen, and `Esc` to close fullscreen. Save & Next uses a short checkpoint transition and immediately opens the next fixed queue item.
6. Use **View original** when thumbnail detail is insufficient.
7. Flag uncertain entries for personal review; no other judge sees the flag.
8. Open Review to filter All, Completed, Incomplete, or Flagged work and to sign out.

If a save fails, keep the page open and use Retry. If another device saved first, the page shows a conflict and requires refresh; it never silently overwrites the newer score. Do not assume a score is stored until the interface shows Saved.
